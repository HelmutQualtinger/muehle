Mühle

Spielregeln

  1. Setzphase. Jede Spielerin/jeder Spieler hat 9 Steine. Abwechselnd wird je ein Stein auf einen freien Punkt gesetzt.
  2. Mühle. Drei eigene Steine in einer Reihe entlang der Linien bilden eine Mühle. Wer eine Mühle bildet, darf sofort einen gegnerischen Stein vom Brett nehmen.
  3. Schutzregel. Steine, die Teil einer gegnerischen Mühle sind, dürfen nicht entfernt werden — außer alle gegnerischen Steine stehen in Mühlen.
  4. Zugphase. Sind alle Steine gesetzt, zieht man abwechselnd einen eigenen Stein entlang einer Linie auf einen benachbarten freien Punkt.
  5. Fliegen. Hat eine Spielerin/ein Spieler nur noch 3 Steine, darf sie/er auf jeden freien Punkt springen, nicht nur auf benachbarte.
  6. Sieg. Man gewinnt, wenn der Gegner nur noch 2 Steine hat oder keinen legalen Zug mehr machen kann.
